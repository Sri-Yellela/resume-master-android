Native Android companion to Resume Master. Swipe-card job feed,
resume builder with section-level swipe actions, template picker,
PDF export, and full admin panel.

## Interactions
- Velocity-sensitive card stack with spring physics
- Soft swipe right: queue | Hard throw right: apply
- Diagonal swipe: star | Left swipe: skip
- Material swipe actions on resume sections
- iMessage-style action badge notices

## Getting Started

### Requirements
- Android Studio Ladybug (2024.2+)
- Android 9+ device or emulator (API 28+)
- Google Play Developer account ($25 one-time) for store submission

### Run
1. Clone the repo
2. Open in Android Studio
3. Run on emulator or device (⌘R / Shift+F10)

### Build for Play Store
Build → Generate Signed Bundle → Android App Bundle
Upload to Play Console → Internal Testing → Production
